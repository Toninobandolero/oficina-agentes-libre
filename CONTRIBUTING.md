# Contribuciones

**Por ahora no aceptamos pull requests.** Las cerraremos sin revisar; no es nada personal.

El motivo es práctico: este repositorio es la edición Libre (licencia AGPL-3.0), y existe además una edición de pago con más módulos que comparte casi todo el código. Para poder mantener las dos, el código tiene que pertenecer a un único titular. Si aceptáramos código de terceros sin un acuerdo de cesión de derechos, ya no podríamos hacerlo.

## Lo que sí puedes hacer

- **Abrir incidencias:** fallos, dudas de instalación o ideas. Cuanto más concretas (pasos, versión, qué esperabas y qué pasó), mejor.
- **Avisar de un fallo de seguridad**, en privado: mira [SECURITY.md](SECURITY.md).
- **Usarla, estudiarla y modificarla** para tu empresa dentro de la licencia AGPL-3.0. Puedes hacer tu propia copia (fork) y llevarla por tu camino.

## Si un día aceptamos código

Antes pediremos un acuerdo de cesión de derechos (CLA) y lo anunciaremos aquí.

---

*English:* we are not accepting pull requests for now. This repository is the Free edition (AGPL-3.0); a paid edition shares most of the code, so all of it must belong to a single owner. Issues and private security reports are welcome (see [SECURITY.md](SECURITY.md)); forks are welcome under the AGPL-3.0. If we ever accept code, we will ask for a contributor agreement (CLA) first.
